# Incoming Archi exports

Begin with [Working on the Harmonia architecture](../../README.md). The governed
[2C Praxis](../../../markdown/governance/architecture-authoring-praxis.md#submit-once-and-close-the-iteration)
defines deliberate Submission and closure of its Authoring Iteration; the
landing area is not a continuing authoring workspace.

This is the landing area for incoming Archi/Open Exchange exports intended for
future analysis and reconciliation. An artefact appearing here is not automatically
authoritative architecture. It is change/reconciliation input and may contain
semantic changes, presentation changes and known Archi transport transformations.

**Archi export is architecture change input, not replacement architecture repository.**
Compare and reconcile it before accepted changes enter the Harmonia Markdown RAD
or subordinate governed projection metadata. The Solution Architect governs
acceptance. Do not replace the published baseline or source resources with an
incoming export.

Existing Increment 1 diagnostics can read this boundary. Increment 2 architectural
change comparison/reconciliation and presentation replay remain future work.
No incoming export is moved here from the frozen empirical evidence: the original
1.0.6/1.0.7 no-edit exports remain unchanged with their historical proof bundles.

Working state and analysis evidence belong in [processing/ingestion](../../processing/ingestion/README.md),
separate from the incoming exchange files.
