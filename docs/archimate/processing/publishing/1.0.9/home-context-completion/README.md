# RAD-1.0.9 Home-derived naming and navigation completion

The Solution Architect's 2026-10-19 decision is implemented within the currently
unsigned RAD-1.0.9 candidate. The release remains 1.0.9, predecessor 1.0.8.
Final Solution Architect sign-off and human rendering inspection remain pending.
No Information Architecture work or generated View presentation change is included.

## Decision and architectural consistency

The governed decision is in [Architecture Modelling Strategy](../../../../../markdown/governance/architecture-modelling-strategy.md#home-derived-naming-and-navigation).
AX-04 keeps semantics authoritative over tooling; AX-14 keeps Home, responsibility,
identity, containment and navigation distinct; AX-17 preserves unresolved assertions
and ancestor standing. One established explicit Home to a Feature supplies the
same semantic context for both qualified names and principal navigation. The
existing lexical, formal-qualifier and Feature-navigation machinery is reused.
Home is read from explicit directed Associations and semantic source ancestry,
never inferred from Realization, names, folders, Views or responsibility.

## Documentation and tooling

Governed documents changed: Architecture Modelling Strategy; Canonical Identity
and Governed Naming Contract; Archi Navigation and View Convention; RAD/ArchiMate
Model Mapping; Architecture Release Policy. The current Functions, Services and
Processes catalogues carry regenerated names. Resource fields and prior-name
provenance are persisted in [home-derived-metadata.json](../../../../../markdown/governance/baseline/home-derived-metadata.json).
The existing baseline, accepted-ingestion and Home-register captures remain
byte-identical. The amendment names existing resource instances and allocates none.

`home_context.py` recognises applicable explicit Homes, reads their governed
ancestry, calls the shared `qualified_names` and Feature navigation routines,
validates persisted fields, projects principal references and follows each source
for relationship navigation. `synchronise_baseline.py`, `reconcile_108.py` and
`governed_metadata.py` integrate and validate that step. `diagnose_roundtrip.py`
validates current names against the same resource amendments. Report and governance
evidence tools distinguish the current completion from preserved earlier evidence.
Nine new Home-context regression tests and amended reconciliation-preservation tests
cover precedence, the full population, unresolved cases, invalid/multiple Homes,
ancestry failure, immutable identities, source standing and unchanged Views.
