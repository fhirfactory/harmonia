\chapter{Ubuntu Host Preparation \& MicroK8s Add-ons}
\label{chap:host_preparation}

A production-grade Harmonia installation on Ubuntu Linux requires baseline host system tuning, package prerequisites, and specific MicroK8s add-on configurations.

\section{Hardware Prerequisites \& OS Requirements}

\begin{itemize}
    \item \textbf{Operating System}: Ubuntu 22.04 LTS or Ubuntu 24.04 LTS (x86\_64 / 64-bit).
    \item \textbf{CPU / Compute}: Minimum 8 vCPUs (16 vCPUs recommended for multi-tenant deployments).
    \item \textbf{Memory (RAM)}: Minimum 32 GiB RAM (64 GiB recommended).
    \item \textbf{Disk Storage}: Minimum 100 GiB NVMe SSD mounted on \nolinkurl{/var/snap/microk8s/common/default-storage}.
\end{itemize}

\section{Kernel Parameter \& Sysctl Tuning}

High-throughput networking and Infinispan memory-mapped files require host sysctl adjustments in \texttt{/etc/sysctl.d/99-harmonia.conf}:
\begin{lstlisting}[language=bash, caption={Harmonia Host Kernel Tuning Parameters}]
# Allow Infinispan memory-mapped files
vm.max_map_count=262144

# Increase file descriptor limits
fs.file-max=2097152

# TCP socket buffer tuning for high-throughput MLLP
net.core.somaxconn=4096
net.ipv4.tcp_max_syn_backlog=4096
\end{lstlisting}

\section{MicroK8s Installation \& Required Add-ons}

Harmonia requires MicroK8s 1.28+ with five essential add-ons enabled:
\begin{lstlisting}[language=bash, caption={MicroK8s Setup and Add-on Activation Commands}]
# Install MicroK8s Snap
sudo snap install microk8s --classic --channel=1.28/stable

# Add user to microk8s group
sudo usermod -a -G microk8s $USER
newgrp microk8s

# Enable mandatory Harmonia add-ons
microk8s enable dns storage ingress registry:size=30Gi metrics-server
\end{lstlisting}
