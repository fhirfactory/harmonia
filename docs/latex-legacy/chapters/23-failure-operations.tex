\section{Dead-Letter Queue (DLQ) Governance}

Tasks that exceed maximum redelivery attempts (default: 5) are routed automatically to the centralized dead-letter queue:
\begin{equation*}
\texttt{petasos.dlq}
\end{equation*}
Engineers can inspect, repair, and replay poisoned messages via \texttt{iris-console} or administrative CLI utilities.

\section{Kubernetes Health \& Readiness Probes}

All application pods expose Spring Boot Actuator health endpoints:
\begin{itemize}
    \item \textbf{Liveness Probe}: \texttt{GET /actuator/health/liveness} (Period: 10s, Timeout: 3s). Restarts unresponsive containers.
    \item \textbf{Readiness Probe}: \texttt{GET /actuator/health/readiness} (Period: 5s, Timeout: 3s). Validates Artemis, Infinispan, and DB connectivity before routing traffic.
\end{itemize}
