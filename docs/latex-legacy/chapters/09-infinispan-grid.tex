\chapter{Infinispan Distributed Cache Grid}
\label{chap:infinispan_grid}

\section{Clustered Grid Topology \& Protocols}

Harmonia deploys a two-pod StatefulSet (\texttt{infinispan-1}, \texttt{infinispan-2}) exposed via the Kubernetes service \texttt{infinispan-service}:
\begin{itemize}
    \item \textbf{Hot Rod Protocol (Port 11222)}: High-speed binary RPC protocol used by \texttt{iris-befe}, \nolinkurl{ponos-task-processor}, and \texttt{pylai-mllp-in} for sub-millisecond key-value operations and near-cache invalidation.
    \item \textbf{JGroups Cluster Discovery (Port 7800)}: TCP-based peer discovery and symmetric encryption mesh maintaining cluster membership and cache partition state.
\end{itemize}

\subsection{Write-Behind Store Architecture (\texttt{mneme-persistence})}

To isolate low-latency in-memory cache operations from relational database latency, Mneme implements Infinispan's \texttt{NonBlockingStore} SPI:
\begin{itemize}
    \item \textbf{Asynchronous Flushing}: Cache mutations are queued in a write-behind buffer (\texttt{modification-queue-size="1024"}).
    \item \textbf{Dual Store Dispatchers}:
    \begin{itemize}
        \item \textbf{\texttt{FhirRestCacheStore}}: Flushes clinical cache modifications asynchronously via HTTP REST to \texttt{http://mnemosyne-clinical-1:8080/fhir/r5}.
        \item \textbf{\texttt{OperationsRestCacheStore}}: Flushes operational telemetry and sequence updates to \texttt{http://mnemosyne-operations-1:8080/api/operations}.
    \end{itemize}
    \item \textbf{Replication Guarantee}: Because caches use \texttt{REPL\_SYNC}, every grid node maintains an identical copy in memory, providing instant failover if either node restarts.
\end{itemize}

\section{Cache Classification Invariant}

\begin{principlebox}{Operational Cache vs Durable Storage}
Mneme is classified strictly as an \textbf{operational in-memory cache grid}, not durable authoritative storage. While data is replicated across 2 owners in memory to survive single-pod restarts, long-term clinical durability and compliance audit records are owned exclusively by Mnemosyne PostgreSQL databases.
\end{principlebox}
