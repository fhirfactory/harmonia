\chapter{Configuration Property Register}
\label{app:config_register}

This appendix provides the authoritative cross-reference of environment variables, Spring Boot properties, and JVM system flags across all subsystems of the Harmonia platform.

\section{Dual-Dimension Configuration Discipline}

Harmonia strictly bifurcates its operational parameter space into:
\begin{enumerate}
    \item \textbf{Infrastructure Configuration}: Kubernetes CPU/memory requests, limits, PVC sizes, node selectors, readiness/liveness probe thresholds, and network policies (governed via Kustomize in \nolinkurl{deployment/kubernetes/base/}).
    \item \textbf{Application Configuration}: Spring application YAML, WildFly standalone subsystems, ActiveMQ Artemis broker XML, Infinispan cache definitions, and Themis policy thresholds.
\end{enumerate}
