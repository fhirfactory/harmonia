# Historical EA scripts

Current Enterprise Architecture operations have moved to
[enterprise-architecture/tooling](../enterprise-architecture/tooling/README.md).
No file in this directory is a current EA operational entry point.

The EA Python scripts and their tests here remain unchanged historical editions
for originating-checkout replay, migration/adoption evidence and archaeology.
This includes `architecture_continuum.py`, `continuum_workbench.py`,
`continuum_manifest.py`, `publish_continuum.py`, release/evidence helpers and
`verify_continuum_*`. The RAD ingestion/reconciliation/source-succession adapters,
`rads_business_architecture.py` and `architecture_identity.py` are historical
machinery. None is a fallback or supported second current EA location.
Runtime/deployment scripts retain their separate existing purpose.
