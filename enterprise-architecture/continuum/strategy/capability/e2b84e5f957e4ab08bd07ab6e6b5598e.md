# [CT3] External Media Reference Governance

## Architectural content

Durable, controlled references support access to large externally managed media outside ordinary Information Unit persistence, preserving integrity, identity and access context without Harmonia assuming custody of the original media objects.

### Incorporation standing

Catalogue identity `E01.05.04`. The accepted definition is preserved above. Migration verification and source measurements do not establish implementation satisfaction. Existing source qualifications remain in force.
