# [Feature] Twin Event Context

## Architectural content

Twin events retain the context required for their governed work progression. The Digital Twin Behaviour framework establishes the required Twin/Behaviour execution context and determines whether input information needs Twin-centric contextualisation, already has it, or needs none. General inputs remain valid; inputs already fit for processing pass through without artificial conversion or destructive rewriting, preserving original information and governed execution semantics.
