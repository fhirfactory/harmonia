# [Feature] Versioned Reference Data Management

## Architectural content

The lifecycle, approved publication, retrieval and historical referencing of versioned reference datasets are governed, including terminology value sets, application reference data and enumerated values. Consumers can identify and access the applicable dataset version; historical model definitions remain available for interpretation. This does not require every enumeration consumer to retrieve data dynamically at runtime.
