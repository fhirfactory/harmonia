# [CT3] Information Unit–Binary Association Management

## Architectural content

Associate logical Information Units with zero or more supporting binary payloads while preserving the distinct identity, version and lifecycle semantics of both.

### Incorporation standing

Catalogue identity `E01.06.02`. The accepted definition is preserved above. Migration verification and source measurements do not establish implementation satisfaction. Existing source qualifications remain in force.
