# [ImplementationGuideline] Default Development Test and POC Identity Provider

## Architectural content

> **Keycloak + PostgreSQL SHALL provide the default FOSS Identity Provider for Harmonia development, test and POC deployments. Keycloak remains an external, replaceable implementation component and SHALL NOT introduce Keycloak-specific dependencies into Harmonia's Identity.Authentication architecture.**

This assertion is normalised from the governed DesignNote under U12/U15/U16 and the ARB release Praxis. Original candidate/release qualifications and separately deferred implementation details remain in force.

Architectural subject: [SEC-001 — Trusted Authentication](../../../motivation/requirement/e4998b0a132c41afbe610b11869c3297.md).
