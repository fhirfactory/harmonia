# Healthcare Interoperability Standards and Specifications

## Architectural content

#### Strategic Definition
**Healthcare Interoperability Standards and Specifications** comprise the external, open, normative specifications governing healthcare data structures, clinical resource models, exchange semantics, and conformance criteria across enterprise and regional boundaries.

#### Enduring Strategic Role
Harmonia is architected to facilitate vendor-neutral health data exchange across acute, primary, community, and diagnostic healthcare systems. This interoperability cannot be accomplished using proprietary vendor protocols. Harmonia depends directly on consensus-based, open standards to establish:
- Standardised structural and semantic representations for clinical entities (encounters, observations, conditions, medications, diagnostic reports).
- Conformance validation frameworks to assert that emitted and ingested payloads comply with normative specifications.
- Standards-conformant external interaction contracts across the Harmonia boundary.

#### Current Strategic Instance
- **HL7® FHIR® Release 5 Core & Australian Profile Specifications**: The principal contemporary instance of this resource is HL7 FHIR Release 5, alongside Australian jurisdictional profile specifications (AU Base and AU Core).
- **Technology Independence**: The strategic resource is the **specification and standard itself**, not any specific implementation framework or runtime library (such as HAPI FHIR). The strategic dependency endures regardless of which runtime software serialises or deserialises the specifications.
