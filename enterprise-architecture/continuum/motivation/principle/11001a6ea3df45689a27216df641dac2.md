# Governed Asynchronous Change Management for Directory Entities

## Architectural content

HTTP POST and PUT interactions on directory resources represent requests for change rather than immediate direct mutations of authoritative state. Every write request generates an immutable ProviderRegistryChangePragma, undergoes validation and automated referential verification in the Energeia pipeline, and commits only upon successful verification.
