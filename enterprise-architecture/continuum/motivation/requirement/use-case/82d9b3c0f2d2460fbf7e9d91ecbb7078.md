# [UseCase] Enrich Provider Records from Multiple Data Sources

## Architectural content

Recognisable interaction: **Enrich Provider Records from Multiple Data Sources**.

The interaction is directed towards the source purpose: Enable the Provider Directory to combine provider information from multiple recognised sources. This supports the target-state objective that uc-3 is implemented as a governed business capability rather than as an isolated technical function. The intended outcome is that a single, more complete provider record is maintained while preserving source authority and provenance.

Source primary actor: Integration Administrator

The interaction retains its source context and conditions. It is not a Journey, Capability or claim of implementation satisfaction.
