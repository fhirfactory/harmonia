# [UseCase] Confirm Provider Status from National Provider Data Store

## Architectural content

Recognisable interaction: **Confirm Provider Status from National Provider Data Store**.

The interaction is directed towards the source purpose: Enable the Provider Directory to verify a provider's current status against an authoritative national source. This supports the target-state objective that uc-5 is implemented as a governed business capability rather than as an isolated technical function. The intended outcome is that provider status used by the Provider Directory is supported by current authoritative evidence.

Source primary actor: National Provider Data Store

The interaction retains its source context and conditions. It is not a Journey, Capability or claim of implementation satisfaction.
