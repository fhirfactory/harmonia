# [UseCase] Supply Care Provider Details to Other Systems via Integration

## Architectural content

Recognisable interaction: **Supply Care Provider Details to Other Systems via Integration**.

The interaction is directed towards the source purpose: Enable the Provider Directory to supply authorised provider information to downstream systems through managed integration. This supports the target-state objective that uc-7 is implemented as a governed business capability rather than as an isolated technical function. The intended outcome is that consumer systems receive current provider information without maintaining unnecessary independent copies.

Source primary actor: Downstream Consumer System System

The interaction retains its source context and conditions. It is not a Journey, Capability or claim of implementation satisfaction.
