## Architectural content

Recognisable interaction: **Share Care Provider Details with Other Systems Using Manual Processes**.

This supports the target-state objective that uc-8 is implemented as a governed business capability rather than as an isolated technical function. The intended outcome is that provider information can be supplied where automated integration is unavailable or inappropriate.
