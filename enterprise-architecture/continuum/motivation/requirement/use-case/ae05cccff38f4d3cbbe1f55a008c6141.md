# [UseCase] Generate Reports on Care Provider Data Integrity

## Architectural content

Recognisable interaction: **Generate Reports on Care Provider Data Integrity**.

The interaction is directed towards the source purpose: Enable the Provider Directory to assess provider data integrity using reporting and exception information. This supports the target-state objective that uc-12 is implemented as a governed business capability rather than as an isolated technical function. The intended outcome is that data-quality issues can be identified, prioritised and remediated.

Source primary actor: Provider Directory Administrator

The interaction retains its source context and conditions. It is not a Journey, Capability or claim of implementation satisfaction.
