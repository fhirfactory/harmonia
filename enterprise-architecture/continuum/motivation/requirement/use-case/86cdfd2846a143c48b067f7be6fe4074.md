# [UseCase] Receive Care Provider Details from National Provider Data Store

## Architectural content

Recognisable interaction: **Receive Care Provider Details from National Provider Data Store**.

The interaction is directed towards the source purpose: Enable the Provider Directory to receive provider information from national provider data sources. This supports the target-state objective that uc-2 is implemented as a governed business capability rather than as an isolated technical function. The intended outcome is that provider information maintained by national authoritative or reference sources is incorporated into the Provider Directory.

Source primary actor: National Provider Data Store

The interaction retains its source context and conditions. It is not a Journey, Capability or claim of implementation satisfaction.
