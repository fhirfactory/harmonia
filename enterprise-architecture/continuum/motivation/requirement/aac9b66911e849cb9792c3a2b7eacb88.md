# INT-002 — Reliable Messaging

## Architectural content

Asynchronous messaging used for governed processing shall provide durable at-least-once delivery. Consumers shall be designed to tolerate duplicate delivery safely.

## ARB source correspondence

Historical INT-002 explicitly requires durable at-least-once messaging and duplicate-safe consumers; catalogue combines those same transport/idempotency obligations. Code differs, meaning corresponds.
