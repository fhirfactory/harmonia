# GovernedReader

## Architectural content

### Approved 1.1.24 incorporation — resulting candidate pending

An explicit IU identity/version read returns that exact version or its factual absence/denial/failure/uncertainty; it never silently substitutes an older/newer version. version=* expresses version selection and is different from an exact-version request (AV-01).

Full GovernedReader obtains authoritative Summary, resolves the opaque ContentMetadata reference with InformationCoordinates through the applicable PersistenceService, **attempts Content materialisation**, and assembles the same complete IU/version. Preserve the established large-binary/media pass-by-reference exception. External Content retrieval is an attempt, not a reachability guarantee; failure/denial/unavailability produces its own read Outcome and does not invalidate earlier Summary CREATE.

Mneme client cacheBehaviour USE_AVAILABLE / RELOAD_FOR_AUTHORITATIVE and persistenceBehaviour NO_WAIT / WAIT_FOR_ACTIVE / WAIT_FOR_AUTHORITATIVE are orthogonal consumer decisions. Version/currency constrains acceptable information; wait behaviour constrains the awaited condition. NO_WAIT can return Failure when no acceptable information is immediately available; ordinary synchronous processing is not zero elapsed time. These conceptual options/defaults/types belong to Mneme's API, not extra inter-component methods. Existing Themis constraints are non-optional.

Following a lost/Indeterminate write, authoritative **GovernedReader(version=*)** may inspect a potentially higher actual persisted version. Sufficient correspondence with the submitted write and required durability evidence must establish reconciliation; a newer version alone, a locally visible record or absence of the requested version does not prove success/failure. Insufficient evidence preserves Indeterminate (MI-06); no supplementary transaction ID.

The IU Summary is the projection of the same accepted InformationUnit excluding **exactly InformationRepresentation.Content**. It retains Identity, applicable Metadata (ManagementContext, InformationCoordinates, SecurityContext, LifecycleContext and optional Relationships), ContainerMetadata and ContentMetadata. A Content reference belongs in ContentMetadata and is opaque to Mneme; Mnemosyne/PersistenceService resolve it with InformationCoordinates. ContentReference is illustrative vocabulary, not a prescribed field encoding. Summary projection does not promote transient ManagementContext data to mandatory durable metadata, create a second IU/InformationRepresentation, independent metadata authority or Summary version lineage. Logical separate Content addressability does not require separate physical databases or a particular native transaction.

All five contracts are synchronous governed request/response, with Calliope-owned factual Outcome (closed Success / Failure / Indeterminate and governed closed Reason vocabulary/extensions). Exact Reason members and stage codes remain deferred. Mnemosyne reports facts; Mneme determines consumer disposition without rewriting them. Transport/session timeout is not a factual operation Failure. Receipt, work acceptance, authoritative effect and end-to-end completion remain distinct.

Authentication and Themis policy apply: Readers require ACCESS + READ, SummarySearch invocation ACCESS + SEARCH and disclosed candidates ACCESS + READ, Writers CHANGE with the requested information operation. Protect identity, metadata, counts, pagination and other existence disclosures as well as Content. RequiredIU/SupportedIU capability matching grants no permission. Preserve source-near audit/provenance, Kleio mandatory capture authority/fail-closed obligations and Dokimasia/Provenance allocations; no blanket candidate event catalogue is promoted. Native database/query/provider values stay below the seam.

Every authoritative full or Summary mutation Success requires the applicable multi-site durable authoritative operation and actual resulting IU version, never cache success, local commit, replication queued or transport ACK. Immutable historical versions are preserved. Mneme retains individual-IU concurrency; eligible Mnemosyne instances must expose one coherent authoritative logical history or factual uncertainty. No extra seam transaction identifier or second version axis is introduced.


The established Harmonia-owned contract supplies authoritative acquisition of governed IU information from Mnemosyne to Mneme. Established absence remains distinguishable from denial, failure, stale/qualified information and uncertainty where the operation contract requires. A successful lookup establishing absence may be Success with an applicable governed reason; this defines no particular Reason enumeration member.

Mnemosyne's Façade participates in the contract; IU governance, conformant construction and persistence execution retain the five-tier allocation. Mneme retains application-facing meaning and post-outcome disposition. The accepted parent DRP establishes this contract's purpose without incorporating or completing the neighbouring interaction draft or selecting a wire/Java/provider interface.
