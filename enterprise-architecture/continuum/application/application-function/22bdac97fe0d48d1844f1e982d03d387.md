# Mneme Adapter / Façade

## Architectural content

### Approved 1.1.24 incorporation — resulting candidate pending

Participate in exactly five upper contracts: GovernedSummaryReader, GovernedSummaryWriter(CREATE, RETIRE), GovernedSummarySearch, GovernedReader and GovernedWriter. SummarySearch refines the existing Search identity; the five-tier internal allocation is unchanged. Register this configured instance's SupportedIU-Criterion using shared TopicMasks; Mneme Store owns RequiredIU-Criterion discovery/selection and complete required coverage checks, independently of Themis. Registration covers the five logical contracts, not uniform native search support. Preserve factual Outcome, same-IU coherence, opaque reference/Content separation, multi-site mutation completion and original-instance continuation. These contracts transfer no cache management to Mnemosyne.

Each Mnemosyne instance's Façade registers its supported IU-type capabilities through the established Topic mechanism. Registrations may be identical, overlapping or disjoint across instances and may cover multiple IU types. This is capability declaration, not IU-instance ownership or evidence of current availability. Mneme's Mnemosyne Adapter (Store), a different responsibility, discovers registrations with the shared TopicMask primitive.

The Façade preserves the relationship to the IU UUID/Topic, applicable versions and operation/stage Outcome. It does not expose a raw provider database as Harmonia's application path. No protocol, registration registry, implementation interface, call stack or deployment boundary is prescribed.
