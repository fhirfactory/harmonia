# InformationUnit Constructor / Disassembler

## Architectural content

Mnemosyne's third responsibility tier decomposes governed IU structure into the logical pieces needed for persistence and reconstructs a conformant governed IU on acquisition. It preserves one atomic IU identity and exactly one InformationRepresentation, UUID/own Topic, applicable Metadata and Content, with no second governed IU merely for provider encoding.

The accepted 1.1.22 Information Unit Framework remains intact: Metadata separates ManagementContext, InformationCoordinates, SecurityContext and LifecycleContext; four coordinate references are TopicIDs. Operational Version and per-cache Active Generation remain Mneme ManagementContext concerns, authoritative durable progression remains Mnemosyne's AX-05 concern, Content Structure Version remains ContentMetadata, and optional native payload instance version remains Content. Provider-native keys/revisions never replace these meanings.

Not every transient ManagementContext field must persist. LifecycleContext supports Mneme–Mnemosyne handshaking. Physical decomposition must permit reconstruction of required governed attributes and unchanged native clinical/business Content. Native encoding/protocol details belong to the Persistence Adapter, and governed Content transformation remains creator/domain responsibility. Optional relationships retain local/remote validation limits, without inferred inverse links or universal graph synchronisation. Large binary pass-by-reference boundaries remain unchanged.

### Incorporation standing

Accepted parent DRP semantics, incorporated under the operative Task for 1.1.23/001. Actual resulting candidate confirmation remains pending. Earlier component/source qualifications remain independently in force.
