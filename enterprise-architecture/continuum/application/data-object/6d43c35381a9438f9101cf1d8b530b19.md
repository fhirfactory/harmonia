# Outcome

## Architectural content

The common Harmonia operation Outcome is a logical information model owned by Calliope under its default ownership of Harmonia models, including domain-specific models. It is not a Mnemosyne-private result, Strategy/Motivation Outcome, IU, native provider response or prescribed implementation Class.

Outcome contains status and reason. Status is the closed enumeration with exactly these accepted identifiers:

| Status | Meaning |
| --- | --- |
| Success | The reporter knows the specified operation succeeded according to that operation's contract. |
| Failure | The reporter knows the specified operation failed according to that operation's contract. |
| Indeterminate | The definitive outcome is not known at the time of reporting: “I don't know at this point.” |

Reason uses an agreed common closed vocabulary plus governed closed domain-specific extensions, including persistence reasons where required. Exact enumeration members are not adjudicated here; none are invented. Reason is operation-contextual and need not uniquely determine status. It is not an unrestricted free-text replacement for the governed vocabularies. Status and Reason are properties/semantics of this model, not mechanically allocated architectural elements.

The reported operation/stage must be clear: request receipt, accepted durable work, verified delegated execution, established authoritative persisted effect and remote/end-to-end completion are distinct. Timeout alone establishes neither success nor failure. Indeterminate does not excuse a provider unable to verify claimed operations, mandate later resolution or prescribe asynchronous reconciliation.

Mnemosyne reports its factual persistence Outcome; Mneme determines its subsequent consumer disposition. Treating an Indeterminate report as failure of Mneme's operation does not rewrite the persistence status. Safe retry and correlation follow owning contracts. This incorporation defines no Java/wire structure, model package, Reason members or provider completion-proof threshold.
