# F-01 implementation gap analysis

- **Inspected state** · `feature/BL-CALLIOPE-OO-01`, `fd52408e3d8be433bb43eedd2a448354646d7518`
- **Comparison** · Existing Calliope model and selected callers versus the [F-01 decisions][f01] consolidated in [Draft.002][draft]

The primary package is `net.fhirfactory.harmonia.model.core.naming`, with `datatypes`, `factory` and `valuesets` beneath it. These exceptions identify changes a separately authorised implementation would need to address. The inspected branch is a pending software candidate. The [architecture findings][reconciliation] control questions about historical identifiers, consumers and dependency placement.

## Material exceptions

| Priority and decisions | Observed public contract and behaviour | Gap and impact |
| --- | --- | --- |
| **P1 · Universal selection and invalid inputs** · F-01.7–F-01.11, F-01.17, F-01.20 | `TopicMask(UUID, MaskType, SortedMap<Integer,String>, SortedMap<Integer,TopicMaskEntryPattern>)` exposes `getId()`, `getType()`, `getMaskType()`, `getNamePatterns()` and `getCanonicalPatterns()`. Null depth policy defaults to Inclusive. The constructor selects a nonempty canonical map before a nonempty name map and otherwise produces an empty mask. An empty Inclusive mask matches any non-null Topic. The builder defaults to Inclusive and permits an empty build. The factory produces unrestricted intent from `unrestricted()`, `nameBased(null)` and blank, `*` or `.*` text under its default policy. [Mask][mask] · [Builder][mask-builder] · [Factory][mask-factory] | Adopt ordered qualifier/value/optional version criteria, structural equality independent of UUID, default exact depth and explicit `all()`. Reject malformed, ambiguous and empty ordinary definitions at construction and adapter boundaries. Do not promote optional/invalid input or an old wildcard to universal control without an approved interpretation. |
| **P1 · Regex timing, engine and error path** · F-01.10, F-01.13–F-01.14, F-01.18–F-01.21, F-01.33–F-01.43 | The name-based branch uses `String.matches` for each comparison, except for an unconditional `.*` shortcut. Malformed name regex can therefore fail at evaluation; the public canonical entry pattern uses `java.util.regex.Pattern`, compiles in its constructor, and embeds raw expression text in validation exceptions. If transient fields are absent, `matches(String, String)` recompiles patterns whenever called. There is no version constraint, release depth/field or complexity bound, evaluation error conversion, or match diagnostic path. [Mask][mask] · [Entry pattern][pattern] | Use the approved RE2/J engine across all three fields, validate and compile once on construction and reconstruction, and consistently preserve full-field and explicit flag semantics. The `.*` shortcut currently accepts candidates RE2/J's default dot would exclude, such as values containing a line break. Establish resource bounds and the Boolean false plus safe ERROR path before using the design in higher-level filtering. |
| **P1 · Topic identity and API compatibility** · F-01.1–F-01.4, F-01.22–F-01.25, F-01.29 | `Topic(UUID, SortedMap<Integer,TopicEntry>)` requires a UUID, offers `getId()` and `getShortId()`, and `getCanonicalName()` returns the sorted map. Its actual equality/hash already ignore UUID and use the map, despite the accepted predecessor's UUID identity. `TopicEntry(String qualifier, String name)` rejects blank fields, exposes `getName()`, has no version field, and is extensible with overridable accessors. `Topic` copies the map while retaining supplied entry instances. The builder generates UUIDs and exposes keyed positions. [Topic][topic] · [Entry][entry] · [Builder][topic-builder] | Change observable identity to escaped non-versioned canonical name and supply a distinct ordered entries API. Preserve deterministic path order, prevent mutable subclass inputs from changing completed entries, generate missing values at assembly, and provide version-insensitive natural ordering. Establish compatibility for the return-type change, UUID references and the current `name` field. Define the qualifier validity rule before translating legacy input. |
| **P1 · Text, logical interchange and subscriptions** · F-01.15–F-01.17, F-01.22–F-01.28 | Topic and mask expose Jackson creator/property shapes under `Serializable` classes. Current Topic data uses `id` and a keyed `canonicalName` of qualifier/name entries. Mask data uses `id`, `maskType` and alternative pattern maps. `TopicFactory.fromName` and `TopicMaskFactory.fromNamePattern` split at dots and trim fields, with special grouping for some unqualified numeric version segments. Formatted output lacks reversible delimiter escaping. `matches(String)` reparses via `TopicFactory.fromName`. [Topic][topic] · [Mask][mask] · [Topic factory][topic-factory] · [Mask factory][mask-factory] | Supply strict qualified and versioned Topic parsing, exact regex-expression parsing, format-independent ordered data and validated reconstruction. Inventory existing snapshots or governed interchange before retiring or adapting constructors, names and UUIDs. Prevent old bare strings from being mistaken for new canonical input. A JSON round trip of the current shape does not establish the future logical contract. |
| **P2 · Names and navigation** · F-01.5–F-01.6, F-01.24–F-01.32 | `getName()`, `getFriendlyName()`, `getRelativeName()`, `getDepth()`, indexed `getEntry(...)`, `toCanonicalString()` and `toTopicString()` are present. `toString()` uses the current unescaped qualified path. There is no versioned canonical name, display contract, parent/ancestor API or structural ancestry check. The factory generates `N<i>` qualifiers for bare segments. [Topic][topic] · [Topic factory][topic-factory] | Preserve retained versions in navigation and supply the complete name surface. Keep legacy five-coordinate `getModelVersion()` (a positional value such as `2.4` or `R5`) distinct from the new optional entry version. Preserve case and whitespace according to the approved field rules. |
| **P2 · Helpers, immutability and diagnostics** · F-01.9, F-01.14, F-01.19, F-01.37–F-01.42 | `TopicMaskBuilder.addNamePattern(...)` and `addCanonicalPattern(...)` expose old regex bases without corresponding explicit literal helpers or version overloads. `TopicMaskEntryPattern` is extensible. `TopicMask.toString()` is diagnostic object text rather than a canonical expression. Naming classes do not emit Harmonia application `LogEvent`s. [Mask][mask] · [Entry pattern][pattern] · [Builder][mask-builder] | Provide immutable literal and regex helpers, protect built values from mutable input and retain exact expression strings. Integrate safe conditional TRACE and ERROR with the approved application logger. Prove evaluation and diagnostic failure behaviour, concurrent reuse and bounded performance. |

## Consumer and dependency impact

- **Calliope composition.** `InformationUnitMask` composes TopicMasks for identity, classifications, origin and coordinates. `OperationalMetadataMask` uses them for subject and context. `InformationSecurityContext` carries required compartment and other masks. The direct `TopicMask` Java references found are in Calliope. Consumer architecture has broader reach, and the scan does not establish which persisted, configured or external selectors exist. Absence of an optional outer mask and an invalid inner definition need deliberate handling so the latter cannot remove a constraint. [IU mask][iu-mask] · [Operational mask][om-mask] · [IU security context][security] · [Architecture reconciliation][reconciliation]
- **Existing Topic consumers.** The IU `InformationUnitIdentifier` uses `TopicFactory.forInformationUnit`. The current factory builds `Domain=harmonia.Model=mneme.ModelVersion=iu.DataElement=<hex>`, with a UUID string compacted by removing hyphens and normalizing case. This shows the candidate's qualified mapping, which requires separate architectural confirmation. `ErgonPayloadFhirConverter` emits `toTopicString()` and reads via `TopicFactory.fromName`. Ponos emits `toTopicString()` in `HIE_TOPIC`. Round-trip or migration decisions should account for the omission of qualifier and version fields from unqualified projections while respecting existing format contracts. [IU identifier][iu-id] · [Topic factory][topic-factory] · [Topic value sets][topic-values] · [Ergon FHIR converter][fhir] · [Ponos producer][ponos]
- **Existing subscriptions.** `TopicSubscription` has its own mutable five-coordinate contract, case-insensitive trimmed literal comparisons and null/blank/`*` wildcard fields. Praxis seeds these subscriptions and Ponos dispatch calls workflow matching. Those are actual legacy subscription behaviours with independent meanings. An implementation assignment would need to establish whether to retain the interface, adapt selected callers or explicitly migrate it, with regression checks across HL7/FHIR classification and route eligibility. [TopicSubscription][subscription] · [Praxis seed][praxis] · [Ponos dispatcher][dispatch]
- **Build dependencies.** The inspected Maven files declare no RE2/J dependency. Calliope already declares Jackson and SLF4J, with Logback in test scope. Add or allocate the RE2/J dependency only under the approved library boundary, pin the version and verify capabilities and licences. Establish the approved application logging API and configuration for the console/satellite paths. The model has no established requirement for a dependency on Themis core, Kleio, rsyslog or log persistence. [Calliope POM][pom] · [Architecture reconciliation R5–R6][reconciliation]
