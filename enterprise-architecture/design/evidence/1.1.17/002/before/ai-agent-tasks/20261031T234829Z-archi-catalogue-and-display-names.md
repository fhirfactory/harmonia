Simplify Harmonia's ArchiMate publication and round-trip machinery by replacing inferred Model Tree organisation with a deterministic architectural element catalogue.

### 2.2 Relationship catalogue

Relationships are organised under:

`Relations/Catalogue/<Source Element>/`

Each relationship must appear under the directory corresponding to its explicit source element.

Requirements:

1. Create one source directory for each element with outgoing relationships.
2. Place all relationships originating from that element directly within its source directory.
3. Do not introduce relationship-type subdirectories.
4. Preserve the canonical identity and properties of every relationship.
5. Resolve source directories using governed element identity, not element names alone.
6. Use an appropriate readable directory label derived from the source element.
7. Handle naming collisions deterministically without merging distinct source identities.

Relationship direction is determined exclusively by the explicit relationship source and target.

Directory placement must not create, reverse, reinterpret or otherwise modify architectural relationships.
