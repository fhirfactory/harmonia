# Continuum Manifest

The structural/catalogue publication of the canonical Continuum is maintained
here, relocated from `enterprise-architecture/continuum/documentation/` in 1.1.8.
The root Continuum `MANIFEST.md` remains its existing generated navigation
projection; individually represented Markdown elements remain canonical.

Current publication (**1.1.10**): [browser](published/1.1.10/continuum.html),
[element index](published/1.1.10/README.md),
[ArchiMate Exchange](published/1.1.10/Harmonia-Architecture.xml),
[LaTeX catalogue](published/1.1.10/continuum-catalogue.tex), and
[fully numbered hierarchy](published/1.1.10/navigation.json).

Canonical [navigation.json](../../continuum/navigation.json) supplies organisation.
The Manifest, browser, index, catalogue, Exchange projection and narrative RAD
expose the same complete coordinates. Canonical IDs remain identity; native
ArchiMate type, standing and relationships remain independent of navigation.
The browser defaults to the architecture hierarchy and can search coordinates,
names, identities and content or filter by native type/currentness. No generated
publication independently classifies or accepts architecture.

The 1.1.8 relocation history is preserved below; 1.1.10 leaves historical
publications unchanged.
Retained 1.1.5, 1.1.6 and 1.1.7 publications move with this product. Relative
source links are rebased and their publication hashes refreshed; historical XML
and PDF bytes remain unchanged. Historical PDF printed relative paths describe
their original publication context. Exact relocation correspondence is retained
in [1.1.8 evidence](../../design/evidence/1.1.8/001/after/manifest-relocation.json).

Generate using `make -C enterprise-architecture/tooling continuum`.
Read the [Continuum RAD](../continuum-rad/README.md) for the narrative publication.
