# Regression-fixture dependency analysis — 2026-10-20

## Executive summary

**Most processing-carried regression inputs are representative specimens, not intrinsically historical specimens. Some assertions embedded in the maintained suite are historical integrity or replay checks.** The distinction must be made within test classes and sometimes within a single method.

The maintained tests protect canonical identity through native retyping and representation rebinding; authored semantics against stale derived metadata; current containment against preserved historical assertions; Composition against Aggregation, Home and visual nesting; recursive workspace navigation including contained leaves; non-destructive metadata, reconciliation and release projection; protected authored Views; and fail-closed validation. Those properties need distinguishable states and carefully chosen characteristics. They do not generally require the specimens to have participated in Run-001, Run-002 or a particular RAD promotion.

There is a narrow, explicit history-essential regression: the diagnostic for the **original RAD-1.0.6 identity gap** must continue to recognise that released state rather than project today's metadata backwards. Its principal specimen is already a governed publication, outside processing. The frozen v0.2 recovery corpus and real Archi exports are valuable examples of earlier representations and tool behaviour, but most tests using them exercise current machinery against representative characteristics. Authentic export provenance helps establish what a tool actually emitted; reproducing that execution is a different purpose.

The principal historical-assurance dependencies are exact namespace relocation of the ten non-RAD 1.0.14 files; frozen Run-002 source/output integrity; saved Run-001/Run-002 rebinding and verification claims without live recomputation; preserved submission/review hashes; and the historical adoption verifier's execution/census/preservation clauses. These are **REPLAY/AUDIT → Class 5**, even when reached from a maintained unittest. Some historical checks are hidden in loaders used by otherwise valid behavioural regressions.

No evidence establishes that an entire processing run, the complete 75-member recovery boundary, the 127-member protected-file population, all 88 machinery snapshots, or all 647 presentation before-map rows is semantically necessary for current behavioural regression coverage. Whole-model preservation tests do quantify over all elements, relationships or Views in their selected model. That is a meaningful whole-model check; it does not extend necessity to surrounding logs, tools and reports.

This report makes no fixture-selection, migration, retention or disposal decision. No fixture, test, framework, architecture, presentation, governance, release or evidence was changed. The existing RAD-1.1.1 applicability issue is recorded only as an execution limit.
